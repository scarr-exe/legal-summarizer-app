# Runtime dependencies for the deployed application.

# PYTHON VERSION: 3.11, pinned in .python-version next to this file.
# Not optional. spaCy 3.7.4 ships no wheels for Python 3.13, so a builder
# defaulting to 3.13 (Railway's railpack does) falls back to compiling
# spacy -> thinc -> blis from source, and that build fails. Upgrading
# spaCy instead is not a free swap: en_core_web_sm 3.7.1 is pinned to the
# 3.7.x line, and the whole NLP pipeline was measured against it.
#
# The heavy ML stack (torch + transformers, ~1.1GB installed) is NOT here
# on purpose -- see requirements-ml.txt. The summarization pipeline's
# primary path is extractive + rule-based and needs only spaCy; the
# pretrained model is an optional secondary path that fires on a small
# minority of clauses and usually loses the near-copy check anyway.
# Keeping it out of the default install cuts about a gigabyte from the
# deployed image and avoids a 1.2GB model download on every cold start
# (container filesystems are ephemeral, so the cache never survives).
